# FlexPulse

Premium wellness technology e-commerce frontend (frontend-only, mock data).

## Tech stack

React 19, TypeScript (strict), Vite, React Router, Tailwind CSS v4, shadcn/ui + Radix, Motion, Zustand, React Hook Form + Zod, Vitest + RTL.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

- `npm run dev` — dev server
- `npm run build` — typecheck + production build
- `npm run lint` — ESLint
- `npm run test` — Vitest
- `npm run preview` — preview production build

## Notes

- Cart persists to localStorage via Zustand persist.
- Checkout is a frontend demo; no real order is placed.
- Reviews are clearly labeled placeholders.
- Prices and specs are mock values.
